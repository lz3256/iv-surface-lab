# IV Surface 真实数据初始实验归档

使用用户提供的 optionsDX SPX 日频期权链和 CRSP SPY 数据，研究隐含波动率特征对收益及波动率预测的增量信息。实际输入与评估划分见 [PROTOCOL.md](PROTOCOL.md)。

本公开目录保留研究代码、协议、汇总结果和中文解读；供应商原始数据、处理后市场输入、逐日预测及本地审计快照不在此公开版本中。

- [研究结果](研究结果.md)：核心发现和限制。
- [补充解读](补充解读.md)：逐年稳定性与简单基线比较。
- [数据核验](数据核验.md)：原始输入问题及曲面筛查。
- [汇总比较表](results_summary.csv)：开发期与留出期模型比较。
- `code/`：曲面适配器、研究引擎与测试。

复现实证结果需要自行获得相应数据并重建输入。可运行的独立合成演示与安装说明见 [项目主页](../../README.md)。

合约结算类型和历史可得时点未独立核实。留出期已经使用，后续改模型需要新的未见数据才能做独立确认。
