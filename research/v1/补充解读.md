# 补充解读：哪些结果有意义

这份补充说明使用已经保存的预测结果作描述性汇总，没有重训模型或更改参数。逐年同向改善不等于11次独立显著检验。

**值得继续研究的方向是波动率预测，而不是把目前结果包装成方向交易信号。**

## IV水平的跨年表现

在HAR历史波动率模型上加入ATM IV，5日对数方差预测在2012—2022年的全部11个年份改善；21日在9个年份改善。首尾年份不是完整年度。正数表示MSE降低。

| 年份 | 5日误差降低 | 21日误差降低 |
|---|---:|---:|
| 2012 | +26.71% | +23.25% |
| 2013 | +28.79% | +21.94% |
| 2014 | +36.06% | +17.57% |
| 2015 | +12.44% | -0.03% |
| 2016 | +28.95% | +15.39% |
| 2017 | +41.51% | +46.15% |
| 2018 | +12.77% | -5.05% |
| 2019 | +15.19% | +2.17% |
| 2020 | +21.19% | +14.68% |
| 2021 | +18.12% | +13.73% |
| 2022 | +31.76% | +20.83% |

留出期的5/21日改善分别为24.27%和35.58%。21日比较的辅助家族Holm p≈0.048，全13项校正p≈0.052；5日留出期的辅助Holm p≈0.584。应同时看改善幅度、跨年方向和统计不确定性。

## 曲面复杂度的含义

在HAR＋IV基础上额外加入期限结构、偏斜水平和曲率，表现不稳定；21日波动预测的开发期和留出期都变差。这支持先保留较简单的HAR＋IV基线，不能据此断言所有非线性或其他曲面方法都无效。

风险预测、仓位大小和波动率管理是后续待测试的用途，本次没有验证这些用途带来交易收益。合约结算口径、历史可得时间以及只有约一年的留出期仍限制结论。
