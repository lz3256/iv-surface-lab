# IV Surface 稳健性扩展归档

这是 H2 稳健性补丁、结算周期诊断及固定规则重跑。它沿用初始样本，属于探索性分析。先阅读 [研究说明](研究说明.md) 和 [协议](PROTOCOL.md)。

本公开目录包含 `code/`、上述研究文档及 [汇总比较表](results/comparisons.csv)。原工作包中的供应商输入、旧输入和逐日预测快照、详细诊断及本地核验文件已排除。

复现实证扩展需要自行获得数据并重建初始实验输入与预测。脚本中的 `--v1` 指向自行准备的初始实验目录。安装和合成演示见 [项目主页](../../README.md)。

这些分析没有识别或修复 AM/PM 结算差异；数据可得时点与开盘成交仍为研究假设。
