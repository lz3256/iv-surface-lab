# IV Surface 后续探索归档

本轮继续使用 2010–2023 年样本，研究残差化特征、同端点比较及事件扩展。先阅读 [研究说明](研究说明.md) 和 [协议](PROTOCOL.md)。原留出期已被反复使用，全部发现均属于探索性结果。

本公开目录保留 `code/`、协议、中文解释，以及 `results/` 下的汇总比较和旧置信区间换算表。供应商输入、逐日预测、事件输入和实验快照已排除。

`comparisons.csv` 中的增量 R² 使用小数比例，乘 100 后才是百分数。旧预测区间换算不构成新样本证据。

完整复现需要自行提供相应数据、事件日历及前两轮实验快照。安装和独立合成演示见 [项目主页](../../README.md)。
